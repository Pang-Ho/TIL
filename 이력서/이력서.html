비즈테크아이 · LG이노텍

2026.01 — 현재

AWS EKS 기반 15개 표준 시스템 인프라 운영, 과제 관리 시스템 고도화 및 프론트엔드 기술 가이드 담당

Problem
무한 스크롤 과제 목록에서 카드마다 아이콘을 노출해야 했으나 S3가 백엔드와만 통신하는 구조라 프론트에서 직접 조회가 불가했고, 정확히 일치하는 검색만 지원해 원하는 과제를 찾기 어려웠음
Solution
화면에 노출되는 데이터의 ID만 모아 Presigned URL을 발급받고 React Query 상태로 관리, 노출된 ID는 캐시해 재진입 시 재요청을 방지. 데이터 규모(1만 건 미만)를 고려해 Fuse.js 기반 실시간 유사 검색을 도입
Result
불필요한 이미지 API 호출을 제거하고 키 입력 즉시 반응하는 검색 UX를 구현. 별도로 Jenkins 빌드 메모리 이슈를 Lazy Loading·정적 파일 이동으로 해결해 서버 비용 30% 증가를 방지

과제 관리 시스템 고도화 개발 리더

비즈테크아이 · LG이노텍

2025.06 — 2025.09

과제 관리 시스템에 검증·평가 로직을 추가하는 고도화 프로젝트를 개발 방향 결정부터 리드

Problem
금액 입력 화면이 14개 항목을 건별로 저장하는 구조라 엑셀 데이터 입력 시 API를 최대 14회 호출해야 했고, 검토·결재 로직이 화면마다 분산되어 재사용과 유지보수가 어려웠음
Solution
상위 컴포넌트에서 전 항목 데이터를 통합 관리하도록 리팩토링하고 React Hook Form + Zod로 일괄 저장을 구현. 검토·결재 로직은 useReview 커스텀 훅과 단일 공통 결재 컴포넌트로 모듈화
Result
조회·저장 API 호출을 최대 14회 → 1회로 단축, 공통 모듈화로 유사 업무 개발 공수 약 50% 절감. 변경 항목의 탭 배경색 자동 변경으로 업무 가시성과 사용자 만족도 향상
